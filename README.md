# VisionPlay

Phone-first gesture gaming platform prototype.

## Vision

VisionPlay is a web-based gesture gaming prototype where the player uses their phone camera to control gameplay with hand motion. The first version is **phone-first**: the game runs directly on the phone, and the screen can optionally be mirrored to a TV.

## Initial product direction

- **Mode:** Phone-first
- **Primary demo:** Gesture-controlled slash game
- **Display:** Phone screen first, optional TV casting/screen mirroring
- **Goal:** Fast, magical prototype with minimal setup friction

## Repo structure

- `docs/` — product + technical documentation
- `app/` — prototype web client
- `server/` — optional realtime/session backend for later phases
- `scripts/` — local helper scripts
